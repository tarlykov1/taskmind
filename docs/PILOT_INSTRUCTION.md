# Pilot instruction

1. Download `GSPTaskMiningAgentPortable.zip` from Release or from repository `dist`.
2. Extract it into a user-writable folder.
3. Run `START_AGENT.cmd`.
4. Confirm `data/agent-status.txt`, `data/logs/events-*.jsonl`, and `data/logs/events.csv` exist.
5. Use `ENABLE_AUTOSTART.cmd` only when the pilot user agrees to current-user autostart.
