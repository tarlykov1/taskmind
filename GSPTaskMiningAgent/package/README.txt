GSP Task Mining Agent - Windows x64 portable package

Do not download "Source code" ZIP to run the agent. Download release assets instead:
- GSPTaskMiningAgent.exe for a single-file run
- GSPTaskMiningAgentPortable.zip for the portable package

Quick start:
1. Extract this folder to a location where your Windows user can write files.
2. Run START_AGENT.cmd or GSPTaskMiningAgent.exe.
3. Check Task Manager for GSPTaskMiningAgent.exe.
4. Check data\agent-status.txt and data\logs.

Autostart:
- Run ENABLE_AUTOSTART.cmd to create a current-user Startup shortcut.
- Run DISABLE_AUTOSTART.cmd to remove only that shortcut.

No .NET Runtime, .NET SDK, Visual Studio, Python, admin rights, Windows Service, or Task Scheduler setup is required.
