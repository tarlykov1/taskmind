# Инструкция пилота Task Mining Light

## Как выбрать 3–5 сотрудников

Выберите сотрудников, которые:

- регулярно выполняют повторяемые операции в одних и тех же системах;
- работают с заявками, документами, Excel, 1С, Service Desk, CRM или ERP;
- готовы участвовать в пилоте и давать обратную связь;
- представляют разные варианты одного процесса, если процесс выполняется несколькими ролями.

Не стоит включать сотрудников, у которых основная работа связана с чувствительными персональными данными, коммерческой тайной или нерегулярной творческой деятельностью.

## Portable-запуск без установки

1. Передайте участнику ZIP `GSPTaskMiningAgentPortable.zip` или уже распакованную папку `GSPTaskMiningAgentPortable`.
2. Участник копирует/распаковывает папку в любое место, где у него есть права на запись.
3. Участник проверяет `config.json` рядом с `GSPTaskMiningAgent.exe`.
4. Участник запускает `GSPTaskMiningAgent.exe`.
5. Если агент должен запускаться вместе с Windows, участник запускает `scripts\enable_autostart_user.bat`.
6. Для отключения автозагрузки участник запускает `scripts\disable_autostart_user.bat`.
7. Для полного удаления нужно отключить автозагрузку, завершить агент и удалить portable-папку.

Административные права не требуются, если папка находится в месте, доступном пользователю на запись. Планировщик задач, MSI и службы Windows не используются.

## Как проверить сбор логов

1. Откройте несколько рабочих приложений.
2. Переключитесь между окнами.
3. Проверьте папку `data\logs` внутри portable-папки.
4. Убедитесь, что появились `YYYY-MM-DD_events.jsonl` и `YYYY-MM-DD_windows.csv`.
5. Если скриншоты включены и правила сработали, проверьте `data\screenshots\YYYY-MM-DD`.
6. При проблемах смотрите `data\errors\agent_errors.log`.
7. Повторный запуск EXE не должен создавать второй активный экземпляр агента.

## Как проверить автозагрузку

1. Запустите `scripts\enable_autostart_user.bat`.
2. Проверьте наличие ярлыка `GSPTaskMiningAgent.lnk` в `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.
3. Перезагрузите Windows или выйдите из сеанса и войдите снова.
4. Проверьте, что в `data\logs` появились новые события `agent_start`.
5. Запустите `scripts\disable_autostart_user.bat` и убедитесь, что ярлык удален.

## Как собрать архивы

Архивы предыдущих дней создаются при следующем запуске агента, если `agent.archiveDaily = true`. Архивы находятся в:

```text
data\archives\YYYY-MM-DD_PC-NAME.zip
```

Если включено копирование на сетевую шару, проверьте папку:

```text
\\your-file-server\task-mining-pilot\PC-NAME
```

## Как получить отчет

```bat
cd GSPTaskMiningAgent
pip install -r analyzer\requirements.txt
python analyzer\analyze_logs.py path\to\GSPTaskMiningAgentPortable\data\logs -o task_mining_report.xlsx
```

Если анализируются архивы с нескольких ПК, распакуйте их в одну рабочую папку и передайте эту папку анализатору.

## Как интерпретировать результаты

- `summary` показывает общий объем событий, переключений, скриншотов и долю простоя.
- `applications` помогает увидеть, где пользователь проводит больше всего времени.
- `window_titles` показывает типовые окна и операции.
- `process_chains` показывает повторяющиеся переходы между приложениями.
- `screenshots` помогает выборочно восстановить контекст операций.
- `errors` показывает проблемы сбора данных.

## Какие процессы считать кандидатами на RPA

Хорошие кандидаты обычно имеют несколько признаков:

- высокая повторяемость цепочки приложений;
- частые переключения между системами;
- ручной перенос данных между окнами;
- длительная работа с однотипными заявками или документами;
- понятные входные и выходные данные;
- низкая доля экспертных решений;
- стабильные экраны и правила обработки.

После анализа логов обязательно проведите интервью с участниками пилота: логи показывают паттерны, но не заменяют описание бизнес-правил.
