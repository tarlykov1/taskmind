# SECURITY

## Модель безопасности

`GSPTaskMiningAgent` работает локально в пользовательской сессии Windows и по умолчанию сохраняет данные только внутри portable-папки агента в каталоге `data`. Сервер, внешняя БД, MSI, службы Windows, Планировщик задач и административная установка не используются. Единственная опциональная передача данных — копирование дневного ZIP-архива на внутреннюю сетевую шару при `agent.copyArchiveToNetworkShare = true`.

## Собираемые данные

- дата и время события;
- имя пользователя или хеш имени;
- имя рабочей станции;
- имя активного процесса;
- заголовок активного окна или маска `[masked]`;
- домен из заголовка браузера, если его удалось эвристически определить;
- длительность активности в окне;
- признак простоя пользователя;
- путь к скриншоту, если скриншот был сделан;
- технические ошибки агента.

## Данные, которые не собираются

- вводимый пользователем текст;
- пароли;
- содержимое буфера обмена;
- скрытая видеозапись экрана;
- содержимое документов, писем и файлов;
- история браузера;
- содержимое веб-страниц;
- данные из внешних сервисов.

## Рекомендации для согласования с ИБ

- Зафиксировать цель пилота: поиск кандидатов на RPA, а не контроль сотрудников.
- Передать ИБ `config.example.json`, правила скриншотов и структуру локального хранения `data`.
- Решить, нужно ли включить `privacy.hashUserName` и `privacy.maskWindowTitles`.
- Ограничить доступ к portable-папке и архивам только участниками пилота и ответственными аналитиками.
- Если используется сетевая шара, настроить ACL на папку `\\your-file-server\task-mining-pilot`.
- Проверить, что `agent.copyArchiveToNetworkShare` выключен, если передача архивов не согласована.

## Уведомление участников пилота

До запуска агента рекомендуется письменно сообщить участникам:

- период пилота;
- какие данные собираются;
- какие данные не собираются;
- где хранятся данные;
- кто имеет доступ к отчетам;
- как отключить автозагрузку и удалить portable-папку.

## Срок хранения данных

Рекомендуемый срок хранения пилотных данных — 30 календарных дней после завершения анализа. Для продуктивного использования срок должен быть утвержден внутренними правилами компании.

## Порядок удаления логов

1. Отключить автозагрузку через `scripts\disable_autostart_user.bat`.
2. Проверить, что процесс `GSPTaskMiningAgent.exe` не запущен.
3. Удалить portable-папку агента вместе с каталогом `data`.
4. Если архивы копировались на сетевую шару, удалить папку соответствующего ПК на шаре.
5. Зафиксировать удаление в журнале пилота.
