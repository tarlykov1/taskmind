# GSPTaskMiningAgent

`GSPTaskMiningAgent` — portable-first Windows-агент Task Mining Light для внутреннего пилота на 3–5 рабочих ПК. Агент собирает локальные технические логи активности и выборочные скриншоты по правилам конфигурации без сервера, без внешней БД, без MSI, без служб Windows и без Планировщика задач.

## Назначение проекта

Проект помогает быстро проверить гипотезы по рутинным операциям, увидеть повторяемые цепочки между приложениями и подготовить список кандидатов на RPA. Это не промышленный аналог Process Discovery, а простой пилотный инструмент, который пользователь может скопировать в папку с правами на запись и запустить самостоятельно.

## Portable-запуск без установки

Основной сценарий пилота:

1. Получить ZIP `GSPTaskMiningAgentPortable.zip`.
2. Распаковать папку `GSPTaskMiningAgentPortable` в любое место, где у пользователя есть права на запись, например в профиль пользователя или рабочую папку пилота.
3. Проверить `config.json` рядом с `GSPTaskMiningAgent.exe`.
4. Запустить `GSPTaskMiningAgent.exe`.
5. Для автозагрузки текущего пользователя запустить `scripts\enable_autostart_user.bat`.
6. Для отключения автозагрузки запустить `scripts\disable_autostart_user.bat`.
7. Для полного удаления отключить автозагрузку, завершить агент и удалить portable-папку.

Агент не требует установленного .NET Runtime на рабочем ПК, потому что поставляется как self-contained `win-x64` single-file EXE. Права администратора не нужны, если portable-папка находится в месте, доступном пользователю на запись.

## Что собирает агент

- имя пользователя или его хеш, если включено `privacy.hashUserName`;
- имя ПК;
- активный процесс;
- заголовок активного окна, если не включено `privacy.maskWindowTitles`;
- время смены активного окна;
- длительность активности в окне;
- факт простоя пользователя по отсутствию активности мыши/клавиатуры;
- выборочные скриншоты только по правилам из `config.json`;
- технические ошибки агента.

## Что агент не собирает

- вводимый текст и нажатия клавиш;
- пароли;
- содержимое буфера обмена;
- скрытую видеозапись экрана;
- содержимое документов, писем и файлов;
- историю браузера и содержимое вкладок;
- данные во внешние сервисы.

## Как собрать portable-пакет

```bat
cd GSPTaskMiningAgent
scripts\build_portable_win_x64.bat
```

Скрипт выполняет self-contained publish для `win-x64`, собирает готовую папку `output\GSPTaskMiningAgentPortable` и ZIP `output\GSPTaskMiningAgentPortable.zip`.

## Где лежат данные

По умолчанию все рабочие данные находятся внутри portable-папки:

```text
data\logs\YYYY-MM-DD_events.jsonl
data\logs\YYYY-MM-DD_windows.csv
data\errors\agent_errors.log
data\screenshots\YYYY-MM-DD\HH-mm-ss_process.jpg
data\archives\YYYY-MM-DD_PC-NAME.zip
```

Путь задается параметром `agent.logRoot`. В portable-сценарии значение по умолчанию — относительный путь `data`, который разрешается относительно папки с EXE.

## Конфигурация

`config.json` ищется рядом с `GSPTaskMiningAgent.exe`. Если файл отсутствует, агент создает его из `config.example.json` в этой же папке.

Чтобы полностью отключить скриншоты, установите:

```json
{
  "agent": {
    "enableScreenshots": false
  }
}
```

В рабочем файле конфигурации оставьте остальные секции из примера.

## Автозагрузка без прав администратора

Включить автозагрузку текущего пользователя:

```bat
scripts\enable_autostart_user.bat
```

Скрипт создает ярлык `GSPTaskMiningAgent.lnk` в `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`. Ярлык указывает на EXE в текущей portable-папке, `WorkingDirectory` также равен portable-папке. Планировщик задач не используется.

Отключить автозагрузку:

```bat
scripts\disable_autostart_user.bat
```

Скрипт удаляет только ярлык автозагрузки и не удаляет логи или portable-папку.

## Debug-запуск

```bat
scripts\run_debug.bat
```

В debug-режиме агент выводит события в консоль. Если экземпляр уже запущен, второй экземпляр корректно завершится и выведет сообщение.

## Как запустить анализатор

```bat
cd GSPTaskMiningAgent
python -m venv .venv
.venv\Scripts\activate
pip install -r analyzer\requirements.txt
python analyzer\analyze_logs.py path\to\GSPTaskMiningAgentPortable\data\logs -o task_mining_report.xlsx
```

Excel-отчет содержит листы `summary`, `applications`, `window_titles`, `process_chains`, `screenshots`, `errors`.

## Пример сценария пилота на 3–5 ПК

1. Согласовать пилот с ИБ, руководителем подразделения и участниками.
2. Выбрать 3–5 сотрудников с типовыми повторяемыми операциями.
3. Собрать portable ZIP и проверить `config.json`, особенно правила скриншотов.
4. Передать участникам portable-папку или ZIP.
5. Участник распаковывает папку в доступное для записи место и запускает `GSPTaskMiningAgent.exe`.
6. При необходимости участник включает автозагрузку через `scripts\enable_autostart_user.bat`.
7. Собирать данные 3–10 рабочих дней.
8. Забрать ZIP-архивы из `data\archives` или папки `data\logs`/`data\screenshots`.
9. Построить Excel-отчет анализатором.
10. Отобрать процессы с частыми переключениями, большим ручным временем и повторяемыми цепочками.

## Риски и ограничения

- Агент видит только активное окно и не понимает бизнес-смысл операции без интервью с пользователем.
- Домен браузера извлекается только эвристически из заголовка окна и может быть пустым.
- Скриншоты могут содержать персональные или конфиденциальные данные, поэтому правила нужно согласовать заранее.
- Длительность считается по polling-модели, точность зависит от `pollIntervalMs`.
- Portable-папка должна находиться в месте, где пользователь может создавать и изменять файлы.
